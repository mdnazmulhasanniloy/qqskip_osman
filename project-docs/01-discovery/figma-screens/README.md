# Figma screen exports

Export each frame from Figma as PNG at 1x and save it here with these names (lowercase, underscores):

- Customer: `customer_<frame>.png` e.g. `customer_home_1.png`, `customer_detail_1.png`, `customer_youre_in_queue.png`, `customer_buy_pass_1.png`
- Business: `business_<frame>.png` e.g. `business_overview_normal.png`, `business_queue_control.png`, `business_live_view.png`
- Website: `web_<frame>.png` e.g. `web_home.png`, `web_pricing.png`, `web_signup_20_plan.png`
- Admin: `admin_image_01.png` … `admin_image_15.png`

Frame list: see `../figma-screen-inventory.md`.
Tip: in Figma select all frames on a page → Export → PNG 1x → Export, then rename.
