## How to use it with Claude Code

Option A (best): connect the Figma Dev Mode MCP server in Claude Code, then Claude can read a frame
by its link (right-click frame → Copy link to selection).

Option B: export every frame as PNG 1x into `figma-screens/` using the names in
`figma-screens/README.md`. Claude Code can read images.
