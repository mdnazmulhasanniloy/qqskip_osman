# Qskip · project-docs index

Single source of truth for every Claude session in every repo. Read this file first.
Rule: if it is not in these docs, it does not get built. Unclear → `05-delivery/blockers.md`, never guess.

## Product in one paragraph

Qskip is a virtual-queue marketplace (UK, prices in GBP). Customers see live wait times of venues
(restaurants, cafes, bars, food trucks, events) on a map, join a queue, reserve, or buy a one-time
**Q Skip Pass** to skip the line. Venues run their queue from a tablet app; Pro venues get a
FootfallCam people-counter that updates the queue automatically. Qskip earns business subscriptions
(Basic £10 / Pro £30 per month), customer subscriptions (£5.99/month) and 15% commission on passes.

## Source-of-truth order (when two inputs disagree)

1. Client answers in `01-discovery/meeting-notes/` (newest wins)
2. `01-discovery/client-docs/qskip-spec.md` → decides **what** is built (features, rules, numbers)
3. `01-discovery/figma-comments.md` → overrides the Figma screens
4. Figma screens (`figma-screens/`, `figma-screen-inventory.md`) → decide **how it looks**
5. Anything else → it is a blocker, write it in `05-delivery/blockers.md`

## Generation order (planning phase)

`/gen-prd` → review + client sign-off → `/gen-journeys` → `/gen-design` → `/gen-arch` → `/gen-tasks`.
Run each from the root folder `qskip/`, in plan mode, `/clear` between them.
